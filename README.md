# 🕐 What time is it? — 4학년 영어 듣고 따라 말하기

초등학교 4학년 영어 **"What time is it?"** 단원의 문장을 **듣고 따라 말하며 발음 정확도**를 측정해 보는 웹 앱입니다.
영어 수준이 낮은 학생도 쉽게 익히도록 문장을 **두 조각으로 나눠 배우고, 직접 조합**하게 만들었습니다.
[`3th-grade-_-Do-you-like`](https://github.com/z2x3c4v5/3th-grade-_-Do-you-like) 페이지의 양식(무지개 테마·탭·음성 합성·정확도 측정)을 참고했습니다.

## 다루는 문장

묻는 말은 언제나 **"What time is it?"** 이고, 대답은 **시간 + 할 일** 두 조각으로 이루어져요.

| 시계 | 시간 (① It's ~) | 할 일 (② It's time for ~) |
|------|------------------|----------------------------|
| 🕗 8:00 | It's 8 o'clock. | It's time for breakfast. |
| 🕣 8:30 | It's 8:30. | It's time for school. |
| 🕘 9:00 | It's 9 o'clock. | It's time for class. |
| 🕛 12:00 | It's 12 o'clock. | It's time for lunch. |
| 🕕 6:00 | It's 6 o'clock. | It's time for dinner. |
| 🕤 10:30 | It's 10:30. | It's time for bed. |
| — | (시간 탭에서 자유 선택) | It's time for homework. |

> **시간 말하기 탭**에서는 위 6개에 얽매이지 않고 **1~12시 정각/30분을 자유롭게 골라** 읽기 연습을 할 수 있어요. 할 일에는 **homework(숙제)** 도 추가되었습니다.

> 30분 단위는 화면에 **`It's 8:30.`** 처럼 보여주고, 들을 때는 자연스럽게 *"It's eight thirty."* 로 읽어줘요.

## 탭 구성

- **🕐 시간 말하기** — 학생이 **① 몇 시 (1~12시) ② 정각/30분** 을 직접 골라요. 고른 시각이 아날로그 시계에 나오면 🔊 로 듣고 **🎙️ 마이크로 따라 읽어 정확도**를 바로 확인해요. (`It's 3 o'clock.` / `It's 3:30.`) ⭐ 로 담아 더 연습할 수도 있어요. → 정각 12개 + 30분 12개, 모두 연습 가능!
- **🍽️ 할 일 말하기** — `It's time for breakfast.` 처럼 **할 일 대답만** 익혀요. 그림 + 🔊 듣기 + ⭐ 담기.
- **🧩 조합하기** — ① 시간을 고르고 ② 할 일을 고르면 한 문장(`It's 8 o'clock. It's time for breakfast.`)이 완성돼요. 🔊 로 듣고 **⭐ 연습 목록에 추가** 로 정확도 연습 탭에 보내요.
  - **빼기**: 담은 문장의 버튼을 다시 누르면 연습 목록에서 빠져요. (고른 칩도 다시 누르면 선택 취소)
  - **헛조합 방지**: 어울리는 시간대의 짝만 만들 수 있어요. 예) `아침 8시 + 저녁`, `9시 + 학교` 처럼 맞지 않는 짝은 🤔 안내가 뜨고 담을 수 없어요.
- **🎤 정확도 연습** — ⭐ 로 담은 문장(짧은 조각·조합한 긴 문장 모두)을 **마이크로 따라 말하면 0~100% 정확도**를 측정해요. 정확도·최고점·연습 횟수를 기록해요.

> 영어 수준이 낮은 학생은 **시간 → 할 일 → 조합** 순서로 짧은 문장부터 차근차근 연습할 수 있어요.

## 주요 기능

- 음성 듣기(TTS)와 마이크 정확도 측정(음성 인식) — Web Speech API
- 영어 낱말을 누르면 **발음 + 뜻 풍선** (숫자 `8`, `o'clock`, `thirty` 등도 지원)
- `eight` ↔ `8` 처럼 **숫자 말과 숫자를 같은 것으로 채점**
- 말하기 속도 조절, 연습 기록 **자동 저장**(localStorage)

## 사용 방법

별도 설치 없이 `index.html` 을 브라우저에서 열면 됩니다.

```
git clone <repo>
cd 4th_What-Time-Is-It
python3 -m http.server 8000   # http://localhost:8000
```

> 🎙️ 마이크 정확도 측정과 영어 음성은 **크롬(Chrome)** 에서 가장 잘 동작합니다. 마이크 권한을 허용해 주세요.
